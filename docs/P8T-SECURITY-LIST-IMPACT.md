The operator explicitly rejected a static, manually updated Cloudflare source-CIDR allowlist inside OCI security lists or NSGs. Do **not** produce or apply the previously considered OCI Cloudflare-CIDR replacement. Cloudflare states its origin egress CIDR ranges change infrequently, but they can change; this is still a maintenance dependency.

**Preferred minimal-change candidate for review, NOT yet authorized/accepted:**

Therefore **no live canary** until an independently reviewed, versioned product fix for the official `GET /client/v4/ips` fallback passes CI and real ARM64 acceptance, and the operator verifies startup order, outside-origin direct-IP block, both network families, reboot behavior and rollback. Global AOP is weaker: it only proves the request came from some Cloudflare customer traffic, not the intended zone.
